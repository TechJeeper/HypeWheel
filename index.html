Quick Start Guide

Welcome to HypeWheel — a fast, customizable wheel for random picks.

Add Options
Click a wheel's text area and enter one name per line.
Customize
Use the gear icon () to change colors, images, and spin settings.
Spin
Click SPIN or the wheel itself.
Multiple Wheels
Use + Add Wheel in the header.
Slot Mode
With 2+ wheels, open Slot Mode in the header to spin every list together like a slot machine.
Theater & Overlay
Click maximize for theater mode, or copy an OBS overlay link from Import/Export (Space = spin, R = remove, K = keep).
Winners
Open the trophy in the header to view, copy, or export CSV.

Chrome Extension

Import commenters from X, Facebook, Instagram, TikTok, or Google Sheets via the free Chrome extension.
